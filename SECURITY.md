# Security Policy

## Reporting a Vulnerability

If you discover a security issue or vulnerability in `agpx`, please do **NOT** open a public issue or discussion.

Instead, please submit a Private Security Advisory via GitHub:
https://github.com/David-Sat/agpx/security/advisories/new

Alternatively, contact the maintainer directly. We will review reports promptly, issue security advisories, and publish patches in a timely manner.
